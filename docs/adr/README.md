# Decision records

Short records of decisions that shape Mbiu, so they aren't undone by accident. Each says what was decided, why, and what it costs.

To change a decision, add a new record that replaces the old one, and mark the old one **Replaced by** the new number. Don't edit an accepted record to say something else.
